## Thoughts / Plans

Finally, my part of the application has reached its final form after connecting all parts.

The user flow turned out to be as follows:

1. The user goes to the **Tests** page
2. Sees a list of tests as cards
   - each card contains:
     - basic information about the test
     - results of the last attempt (if any)

3. Clicks **"Open Test"**
4. Lands on the **Test Overview** page
   - sees:
     - a list of all attempts (date, duration, score)
     - buttons:
       - **Start Test**
       - **Show Answers**

5. Clicks **"Show Answers"**
   - a UI with mistakes is displayed:
     - questions
     - selected answers
     - correct answers
   - the **Back** button returns to Test Overview

6. Clicks **"Start Test"**
   - lands on the **Test Run** page
   - completes the test

7. After finishing, sees the result:
   - percentage of correct answers
   - number of correct answers
   - duration

   Available actions:
   - **View Answers** — view mistakes
   - **Try Again** — retake the test
   - **Back to Tests** — return to the tests list

8. When choosing:
   - **Try Again** → a new test attempt starts
   - **Back to Tests** → returns to the Tests page

## Мысли / Планы

Наконец-то моя часть приложения пришла к конечному виду после соединения всех частей.

Пользовательский сценарий получился следующий:

1. Пользователь заходит на страницу **Tests**
2. Видит список тестов в виде карточек
   - каждая карточка содержит:
     - основную информацию о тесте
     - результаты последней попытки (если есть)

3. Нажимает **"Open Test"**
4. Попадает на страницу **Test Overview**
   - видит:
     - список всех попыток (дата, длительность, результат)
     - кнопки:
       - **Start Test**
       - **Show Answers**

5. Нажимает **"Show Answers"**
   - отображается UI с ошибками:
     - вопросы
     - выбранные ответы
     - корректные ответы
   - кнопка **Back** возвращает на Test Overview

6. Нажимает **"Start Test"**
   - попадает на страницу **Test Run**
   - проходит тест

7. После завершения видит результат:
   - процент правильных ответов
   - количество правильных ответов
   - длительность

   Доступные действия:
   - **View Answers** — просмотр ошибок
   - **Try Again** — повторное прохождение
   - **Back to Tests** — возврат к списку тестов

8. При выборе:
   - **Try Again** → начинается новый тест
   - **Back to Tests** → возврат на страницу Tests
